DanQing DisplayTestApp (Windows x64)
=====================================

EN: Run run.cmd. The four example cards work out of the box.
    Model cards need demo data: download packages from
    https://github.com/chenjinxian/DanQing-Data/releases (data-v1)
    and extract into the data\rpc-dumps\ folder next to run.cmd
    (or run scripts\data\download_dumps.ps1 -DestDir data\rpc-dumps
    from a repo clone). A VC++ 2015-2022 x64 runtime is bundled in bin\.

CN: 运行 run.cmd。四个示例卡片开箱即用。
    模型卡片需要演示数据：从 DanQing-Data 仓 release（data-v1）下载数据包，
    解压到 run.cmd 旁的 data\rpc-dumps\ 目录（或在源码仓里跑
    scripts\data\download_dumps.ps1 -DestDir data\rpc-dumps）。
    bin\ 已随带 VC++ 2015-2022 x64 运行库。
