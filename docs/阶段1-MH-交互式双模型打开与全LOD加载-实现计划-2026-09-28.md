> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DisplayTestApp 的 Start Views 页增加 **JoesHouse** 与 **Properties_60InstancesWithUrl2**（下称 instances60）两个模型的打开入口——点击直接进渲染视图；初始视图与 itwinjs-core display-test-app（DTA）一致（其加载的是 bim 内保存的默认 ViewState）；交互（缩放/平移）按视口选择语义动态加载不同 LOD 的 Tiles；两模型的**视口可达 LOD 全集**字节预先备齐（dump 入库），浏览全程**零 NotFound**。

**Architecture:** ①采集升级（仓外工具）：JoesHouse 全树 sweep + 视口面 drill + **默认 ViewState 参数记录**（provenance.defaultView——DTA `Viewer.ts:185` `getDefaultView` 加载 bim 保存视图，DanQing 无法读 bim db → 采集期记录其 origin/extents/rotation/lens，打开时应用 = "初始视图与 DTA 一样"的唯一零网络路径）；②DumpTileFetcher 多根合并（DI 侧只读 fallback 列表）使 instances60 = sweep ∪ drill 联合域；③App 侧 dump 打开链（StartView 卡片 → 信号 → main.cpp 槽 → app 侧 mount 助手 + 默认 ViewState 应用）；④交互零缺失浏览锁（zoom 泵至饱和+回退+平移，requestLog 对账：域内键零 NotFound + 域外零请求）。

**Tech Stack:** Node/CDP（仓外工具升级）/ C++20 / Qt / GoogleTest。

**Spec:** 用户 2026-09-28 四点指令（见 Goal）+ §8.2 零网络协议 + M-D/M-E/M-G dump 契约与采集工具基础。

## 风险预登记

- **JoesHouse textured 命中**（高概率）：textured 变体消费是 TD-20 遗留的大件（shader 变体 + UV LUT + 纹理上传/绑定链）——命中则本里程碑范围显著扩大，Task 1 盘点后向用户如实报告规模再推进。
- **instances60 联合域仍不全**：drill 只采中心分支，全景浏览（平移到非中心分支）可能暴露 sweep 未覆盖的视口键——补采策略：drill 配方对多目标重采（受坑 16"取景杀 selection"限制——若仍 BLOCKED，如实登记交互限制面[中心分支全通/他分支待机制定位]，不降格判据）。
- **"取景杀 selection"（坑 16）机制未定位**：JoesHouse drill 若复现，同 M-G 登记；若 JoesHouse 不复现 → 该现象是模型相关的，取证价值高（对比两模型差异可缩机制搜索面）——如实记录。
- **默认 ViewState 记录形态**：ViewState 属性（origin/extents/rotation/lens）页内直读的 API 形态以实测为准（vp.view 各字段名断点核实，§11.8）；rotation 的存储形态（YPR 角 vs 矩阵 vs 四元数）按 ViewState3d.ts 序列化语义记录。
- **TileAdmin 全局 fetcher 切换**：app 内多次打开/关闭 dump 视图的 fetcher 归属（现状单全局）——本里程碑按"打开时装、关闭时卸"最小语义，多视图并存的多 fetcher 路由超出范围（登记）。
