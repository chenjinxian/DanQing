## 2. DanQing 现状与差距

**现状**（DtaToolBars.cpp）：5+1 条工具栏（Views/Selection/View Settings/View Tools/
Analysis + deco）分域组织——项散布五处非 DTA 序；下拉按钮各自为政（无单开互斥/
onViewChanged 关闭/only3d 显隐合同）；Measure 按钮**置灰但引擎已移植**（M-O(3) P2）；
Walk 按钮**置灰但引擎已移植**（M-O(3) P1）；View Tools 含 DTA 无的相机/平移/滚屏/环视
按钮与 deco 按钮（Deco/Gltf/Macro/Cesium/Sync 等散布）；顶状态条四件散布底部状态栏
（keyin 在 DtaTools 状态栏装配、FPS、tileLoad——Snap Mode 下拉在 selection 工具栏）；
底部无 showstatus/showerror 双 span。

**断点清单**：
1. 单一主工具栏（26 项 DTA 序）——现 5+1 条分域。
2. Measure/Walk 按钮激活（引擎在、按钮置灰）。
3. DTA 工具栏交互合同（单开互斥/onViewChanged close/only3d 显隐）。
4. 顶状态条行（keyin+FPS+tileLoad+Snap Mode 下拉组合——index.html #status-bar 形态）。
5. 底部 showstatus/showerror 双 span（Utils.output/error 的 Qt 等价）。
6. 非 DTA 工具栏项迁菜单（相机/平移/滚屏/环视/deco/gltf/macro/cesium/sync——DTA
   这些只经 keyin/注册工具；DanQing 留菜单栏裁决下迁 View/Tools 菜单域）。
7. Google Maps 项：DTA config 门（googleMapsUi）——DanQing 无该 config=关 → 不出现
   （与 DTA 关态同形）。
8. Open iModel from disk 激活：QFileDialog 选 dump 包（dumpPackageForModel 目录结构
   探测 + openDumpIModel 既有链）。
