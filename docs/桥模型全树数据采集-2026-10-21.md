## 2. 完整层推导方法（可验证）

参考 `computeChildTileProps`（itwinjs-core@88da8fb9 `core/common/src/tile/TileMetadata.ts:777-853`）：

- 子瓦体积：`bisectTileRange3d/2d` 每次只二分**当前最长轴**（三次调用可连续削同一轴）；
- 空体积：`emptySubRangeMask` 位 `1<<(i + 2j + 4k)`；
- 模型域拒绝：子范围与 `tree.contentRange` 不相交则跳过；
- 叶/放大判定：`decodeTileContentDescription`（:880-940）的 complete/incomplete、tolerance、ContainsCurves、inc/exc≤100 启发式。

工具（`scripts/data/`）：

- `enumerate_frontier.py <depth> <out>`：读取已采父层内容，按上述参考语义枚举下一层**缺失**键（`FRONTIER_ROOTS` 分号分隔多个 dump 根）。
- `merge_frontier.py`：把分块 key-list 采集硬链接合并为一个根，写紧凑 manifest（仅 `treeId/contentId/byteLength/file`；解析器必需字段 + 多根可用性门所需字节数）。

**验证（双向）**：以 d11 层 26,546 个 m1 父瓦推导 d12，得到 138,561 键，与 `bridge-edit-sweep-v1` 实际采集的 d12 集合**逐键完全相等**（pred−manifest=0，manifest−pred=0）。

## 3. 层规模与边界

| 层 | 父层 m1 数 | 推导键数 |
|---|---|---|
| d13 | 138,561 (d12) | 789,004 空间 + 39,536 m2 放大 |
| d14（由 d13 的 20% 样本外推） | 160,464 (部分 d13) | 1,061,168 实测 → **全量约 5.2M** |

结论：d13 为**全局完整**的最后一层；d14 全量约 5M 瓦（数十 GB、十余小时）不具性价比。d14 及更深、以及放大链，按**视口可达面**补采（与 DTA 行为等价的确定性泵 + key-list），见 `BridgeEditLodCoverageDiagnostic` 与 `bridge-edit-mag-missing-*`。

## 4. 本地持有与回退

`bridge-edit-frontier-d13-v1` 2.21GB / 82.9 万文件，不适合入库（GitHub 单文件门与索引规模）：

- `.gitignore` 忽略 `bridge-edit-frontier-d13*/`；
- `dta::dumpPackageForModel("bridge-edit")` 在 `manifest.json` 存在时**条件接入**为第 9 根；缺席（新检出）时静默跳过 → 深放大按参考 `hasMissingTiles` 语义退回父瓦 LOD；
- 与既有 140MB 大瓦本地持有同策略；
- manifest 为紧凑形（仅 `treeId/contentId/byteLength/file`，约 91MB）——解析器必需字段 + 多根可用性门所需字节数；打开链在 worker 解析（P-1b 异步），主线程零阻塞。

## 5. 复现命令（仓外 `danqing-rpc-tools`）

```
# 1) 枚举下一层键（合并已有根）
FRONTIER_ROOTS=".../bridge-edit-sweep-v1;..." python scripts/data/enumerate_frontier.py 13 keys.txt

# 2) key-list 采集（推荐驱动：分块+续采+重试，见 §4.1；并发由 sweep.js
#    keyMode 的 MAX_INFLIGHT 控制=32；64 实测触发后端连接失效）
python scripts/data/run_frontier_chunks.py
#    （单块手工形态：node capture.mjs --seed ".../编辑大桥测试.bim"
#      --out ".../frontier-p1" --sweep --sweep-keys keys.txt
#      --sweep-max-tiles 1500000 --sweep-max-bytes-mb 200000 --wait 3600）

# 3) 合并（FRONTIER_CHUNKS 列全部分块目录）
FRONTIER_CHUNKS="...;..." python scripts/data/merge_frontier.py
```
