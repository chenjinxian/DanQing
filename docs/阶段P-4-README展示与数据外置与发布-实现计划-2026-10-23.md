## 四、媒体捕获（P4-d）

- `record_demo.ps1` 窗口录制 → `frames_to_gif.py`（Pillow 组装）三 GIF 入 docs/screenshots：
  ①hero=bridge-edit 全桥→桥墩 LOD 变焦（4.95MB/115 帧）②instances60 球阵 45% 分位
  剖切（两态翻页）③housemodel Illustration 样式切换（两态）。
- **录制取证三录**：
  1. **DPI 虚拟化**：DPI-unaware 录制进程 GetWindowRect 得逻辑坐标（200% 缩放 ÷2）而
     CopyFromScreen 读物理像素 → 只截左上角 1/4；SetProcessDPIAware 根治。
  2. **WM_MOUSEWHEEL 只路由焦点窗**（本机"滚动非活动窗口"关）：后台录制的
     SetForegroundWindow 可被拒——mouse_event(1,0,0) 空输入获前台权 + GetForegroundWindow
     验证重试闭环；**PostMessage 投 WM_MOUSEWHEEL 该 app 不认**（实测 PostMessage 双模型
     无效、mouse_event 硬件注入有效）；TOPMOST 无济于事（可视性≠焦点）。
  3. **PS 5.1 非 ASCII 吞行**：UTF-8 破折号"—"末位字节 0x94 在 GBK 读法下与换行合成
     双字节字符 → 吃掉换行、下一行参数声明被注释吞掉（`-AimY` 绑定永 null——fx 绑定
     fy 空之谜）；**脚本一律纯 ASCII**（P-1a 已有同款教训的复发，本次破折号+中文双形态）。
- **AUTO_CLIP 修三版**：viewRange z 中位（视锥域含后平面 → zMid 在内容下全裁空）→
  projectExtents z 中位（部分模型又高件主导仍在内容上）→ 内容 z 分位参数化
  （DANQING_AUTO_CLIP=<f>，缺省 0.35）+ 法向 -Z（保球阵裁高件）→ 剖切球半效果成立。
- 七模型画廊 + newbridge 补拍 = `docs/screenshots/models/` 8 图。
